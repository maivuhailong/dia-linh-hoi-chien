ĐỊA LINH HỒI CHIẾN — WEBSITE GITHUB PAGES

1. Giải nén ZIP.
2. Tạo GitHub repository công khai (ví dụ: dia-linh-hoi-chien).
3. Upload tất cả file và thư mục bên trong folder này VÀO THẲNG ROOT của repository (index.html phải ở root).
4. GitHub > Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Mở https://USERNAME.github.io/dia-linh-hoi-chien/ (thay USERNAME và tên repo).
6. Link QR thẻ NV01 sẽ là https://USERNAME.github.io/dia-linh-hoi-chien/archives.html?id=NV01 ; các mã khác tương tự (NV01–NV20, DL01–DL16, PT01–PT12).
7. questions.json chứa 12 câu mẫu; cards.json chứa 48 thẻ trích từ Word. Có thể sửa bằng editor, nhưng phải giữ dấu ngoặc và dấu phẩy JSON.
8. Website không có hệ thống tài khoản hay database. Lượt câu hỏi chỉ lưu khi đang mở trang; tải lại trang sẽ reset.
9. CHƯA có nguồn tham khảo riêng cho 48 hồ sơ trong Word. Hãy đối chiếu và bổ sung trước khi nộp như hồ sơ đã kiểm duyệt.
10. Giao diện chỉ dùng chữ, không dùng ảnh nhân vật chưa kiểm duyệt bản quyền.
